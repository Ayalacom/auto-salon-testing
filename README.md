# AutoSalon Manager

Автосалон жұмысын басқару жүйесі. Оқу практикасы жобасы (ТОО JETQ Group, 2026).

Студент: Нурланова Аяла, топ РПО1-23К.

## Жобаның мақсаты

Жүйе автосалонның күнделікті жұмысын жеңілдетеді: автокөліктер, клиенттер және олардың өтінімдері (көлікті қарау немесе тест-драйвқа жазылу) бір жерде сақталады. Жобаны тестілеу (чек-парақтар, тест-кейстер, Postman, Apache JMeter) осы репозиторийдің басты бөлігі болып табылады.

## Модульдер

| Модуль | Міндеті |
|---|---|
| AUTH | Тіркелу және жүйеге кіру (JWT token) |
| CARS | Автокөліктерді қарау, қосу, өзгерту, өшіру |
| CRM | Клиенттер туралы мәліметтерді басқару |
| APPOINTMENTS | Өтінімдер және тест-драйвқа жазылу |

## Іске қосу (Windows)

Екі бөлек терминал (cmd) қажет.

**1-терминал — сервер:**

```
cd server
npm install
npm start
```

Сервер http://localhost:5000 мекенжайында іске қосылады.

Тек бірінші рет, дерекқор бос болғанда, бастапқы деректерді қосу үшін:

```
npm run seed
```

Назар аударыңыз: `npm run seed` командасы users және cars коллекцияларын тазалап, қайта толтырады. Деректер бар базада оны қайта іске қоспаңыз.

**2-терминал — клиент:**

```
cd client
npm install
npm run dev
```

Сайт http://localhost:3000 мекенжайында ашылады. `/api` сұраныстары Vite proxy арқылы 5000 портқа бағытталады.

## Тест аккаунттары

`npm run seed` орындалғаннан кейін:

| Рөл | Логин | Құпиясөз |
|---|---|---|
| Менеджер | manager | manager123 |
| Әкімші | admin | admin123 |

Клиент аккаунтын сайттағы «Тіркелу» батырмасы арқылы жасауға болады. Бұл тек оқу мақсатындағы тест аккаунттары.

## Негізгі API маршруттары

| Әдіс | Маршрут | Қолжетімділік |
|---|---|---|
| POST | /api/auth/register | ашық |
| POST | /api/auth/login | ашық, token қайтарады |
| GET | /api/cars | token қажет |
| POST, PUT, DELETE | /api/cars | менеджер, әкімші |
| GET | /api/clients | менеджер, әкімші |
| POST | /api/clients | token қажет |
| PUT, DELETE | /api/clients/:id | менеджер, әкімші |
| GET, POST | /api/appointments | token қажет |
| PUT | /api/appointments/:id/status | менеджер, әкімші |

Token `Authorization: Bearer <token>` тақырыбымен жіберіледі.
